This repository contains the code for the meta-analysis of chronic restraint stress (CRS) behavioural studies in Romanò and Menzies 2025 - "The duration of restraint stress in rats has no impact in multiple behavioural tests: a meta-analysis"

A reproducible R environment is provided through `renv`
